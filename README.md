# Echoral legal site (GitHub Pages)

Static pages for App Store Connect:

- `support.html` → Support URL
- `privacy.html` → Privacy Policy URL
- `terms.html` → Terms of Use

## Publish

From project root:

```bash
chmod +x echoral-legal/publish.sh
./echoral-legal/publish.sh
```

First run opens GitHub login in your browser (one time).
